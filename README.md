# 베드락 코드빌더 (Bedrock CodeBuilder)

마인크래프트 베드락 에디션에서 **블록 코딩을 배우는 수업용 프로그램**입니다.
설치 없이 실행파일 하나로 동작하며, 브라우저에서 블록을 조립하면 게임 속에서 그대로 실행됩니다.

에이전트를 움직이는 것은 할 수 있는 일 가운데 하나입니다. 이 밖에도
블록을 놓고 부수기, 몹 소환하기, 원·구·선 같은 도형 만들기, 채팅 명령어와
게임 속 사건(아이템 사용, 블록 설치, 몹 처치 등)에 반응하기를 블록으로 만들 수 있고,
반복·조건·변수 같은 프로그래밍의 기본 개념을 함께 익힐 수 있습니다.

## 준비물

- Windows 10 또는 11 (64비트)
- 마인크래프트 **베드락 에디션** (자바 에디션은 지원하지 않습니다)
- 크롬 또는 엣지 브라우저

## 설치

### 1. 내려받기

[**Releases**](../../releases/latest) 에서 아래 두 개를 받습니다.

- `Bedrock-CodeBuilder-<날짜>.exe` — 프로그램 본체
- `setup.bat` — 최초 1회 네트워크 설정

두 파일을 같은 폴더에 두세요.

### 2. 네트워크 설정 (최초 1회)

`setup.bat`을 **마우스 우클릭 → 관리자 권한으로 실행**합니다.
`✅ 설정이 완료되었습니다!` 가 나오면 됩니다.

> 마인크래프트가 자기 컴퓨터(localhost)에 접속하도록 허용하는 설정입니다.
> 이 과정을 건너뛰면 게임에서 연결이 되지 않습니다.

### 3. 마인크래프트 웹소켓 설정 ⚠️

마인크래프트 **설정 → 일반** 에서 아래와 같이 맞춥니다.

| 항목 | 설정 |
|---|---|
| 웹소켓 | **켜기** |
| 암호화된 웹소켓 | **끄기** |

**암호화된 웹소켓을 켜두면 연결되지 않습니다.** 이 프로그램뿐 아니라 에듀케이션의
클래스룸 모드를 비롯한 대부분의 웹소켓 서비스가 암호화되지 않은 연결을 사용합니다.

#### 에디션별 주의점

**베드락 에디션** — 게임 중에도 설정을 켜고 끌 수 있습니다.

**에듀케이션 에디션** — 게임 중(월드 안)에서는 웹소켓 설정을 바꿀 수 없습니다.
**초기 화면의 설정 → 일반** 에서 변경해야 합니다.

> **초기 화면에서도 웹소켓 설정이 안 눌린다면**
> 당황하지 마시고 마인크래프트를 **완전히 종료했다가 다시 실행**하세요.
> 그 뒤 설정 → 일반으로 들어가면 정상적으로 켜고 끌 수 있습니다.

### 4. 실행

`Bedrock-CodeBuilder-<날짜>.exe` 를 더블클릭합니다.

> **"Windows의 PC 보호" 창이 뜨는 경우**
> 코드 서명이 없는 프로그램이라 나타나는 안내입니다.
> `추가 정보` → `실행` 을 누르면 됩니다.

잠시 후 브라우저에 관리 페이지가 열리고 `✅ 코드빌더 실행가능` 이 표시됩니다.

## 사용

1. 마인크래프트를 실행하고 월드에 들어갑니다 (크리에이티브 모드 권장)
2. 채팅창을 엽니다 (**T** 키)
3. **관리 페이지에 표시된 연결 명령어**를 그대로 붙여넣고 엔터
   (보통 `/connect localhost:3000` 이지만, 포트가 사용 중이면 다른 번호가 표시됩니다)
4. 연결되면 블록 코딩 페이지가 자동으로 열립니다
5. 블록을 조립한 뒤, 마인크래프트 채팅창에 `채팅명령어` 블록에 적은 글자를 입력하면 실행됩니다

### 간단한 예시

`채팅명령어 [앞으로]` → `에이전트 앞으로 1칸 이동하기` 를 연결한 뒤,
게임 채팅창에 `앞으로` 를 입력하면 에이전트가 한 칸 전진합니다.
(명령어에 `/` 는 붙이지 않습니다)

## 자주 겪는 문제

**연결이 안 됩니다**
아래를 순서대로 확인하세요.

1. **암호화된 웹소켓이 꺼져 있는지** — 가장 흔한 원인입니다 (위 3번 참고)
2. 웹소켓이 켜져 있는지
3. `setup.bat`을 관리자 권한으로 실행했는지
4. 자바 에디션이 아닌지 (자바 에디션은 지원하지 않습니다)

에듀케이션 에디션에서 웹소켓 설정이 눌리지 않으면, 게임을 완전히 종료했다가
다시 실행한 뒤 초기 화면의 설정에서 바꾸세요.

**실행하면 창이 바로 닫힙니다**
포트 3000 또는 4000을 다른 프로그램이 쓰고 있을 수 있습니다. 이전에 켜둔 코드빌더가 남아 있다면 작업 관리자에서 종료 후 다시 실행하세요.

**반복 실행이 뒤로 갈수록 느려집니다**
블록 코딩 창이 완전히 가려지면 브라우저가 속도를 늦춥니다. 마인크래프트를 창 모드로 줄여 블록 코딩 창이 함께 보이도록 두면 원래 속도로 실행됩니다.

**에이전트가 반응하지 않습니다**
월드에 에이전트가 소환되어 있어야 합니다. `에이전트 소환하기` 블록을 먼저 실행해 보세요.

**아이템 사용 블록이 동작하지 않습니다**
빵 먹기, 포션 마시기처럼 **우클릭으로 쓰는** 동작만 감지됩니다. 검을 휘두르는 공격은 해당하지 않습니다.

## 종료

관리 페이지 창을 닫으면 프로그램이 종료됩니다.
닫히지 않으면 작업 관리자에서 `Bedrock-CodeBuilder` 프로세스를 종료하세요.
